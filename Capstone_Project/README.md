Population Census and Demographic Insights Data Engineering Pipeline
 
Project Overview
This project establishes an automated end-to-end data engineering pipeline for processing and visualizing Population Census data. The architecture follows the Medallion design pattern, with Bronze-Silver-Gold layers to ensure data quality, scalability, and aacurate reporting.
 
The pipeline ingests raw census data, transforms it through progressive layers of refinement in Databricks, orchestrates the entire workflow using Apache Airflow (Dockerized), and delivers actionable insights via Power BI dashboards. 
 
Data Architecture 
In this project, I have used a Medallion architecture to process data from its raw state to a business-ready format:
Bronze Layer (Raw Data)
Ingestion: Raw census source files are landed into Delta tables "as-is" without schema modifications.
Fidelity: Preserves the original state of the data to support full auditability, time-travel, and the ability to re-run the pipeline if transformation logic changes.

Silver Layer (Cleaned & Transformed)
Data Quality: Performed intensive cleaning including null value handling, deduplication, and standardizing disparate geographic names for States and Districts to ensure a "Single Source of Truth."
Year-Based Aggregation: Created Silver Aggregation tables by grouping the population data by the Census Year. This allows for historical trend analysis and longitudinal comparisons across different decades.

Gold Layer (Analytics & Business Intelligence)
Geographic & Sector Metrics: Created specialized views by grouping data at the State and District levels. These metrics were further segmented by Rural vs. Urban sectors to identify infrastructure needs in developing areas.
Calculated KPIs: Developed high-value business metrics using PySpark logic:
Literacy Index: Calculated as (Total Literates / Total Population) * 100, grouped by State and District.
Employment Ratio: Aggregated by sector (Rural/Urban) to track workforce participation.
Gender Ratio: Derived by comparing male vs. female population counts across specific age brackets.

Technology Stack
Infrastructure: Azure Cloud
Data Processing: Databricks (PySpark, Spark SQL, Delta Lake)
Orchestration: Apache Airflow (running in Docker on macOS/Windows)
Visualization: Power BI Desktop (DirectQuery mode)
Development: VS Code, Python, Bash 

Workflow & Orchestration
The pipeline is orchestrated using a Directed Acyclic Graph (DAG) in Apache Airflow.
Pipeline Logic:
Trigger: Manual or Daily schedule.
Connectivity: Airflow uses the DatabricksRunNowOperator to trigger existing Databricks Jobs using a secure PAT token generated by Databricks.
Flow: Start -> Bronze_Ingestion -> Silver_Transformation -> Gold_Analytics -> Pipeline_Log -> End
Monitoring, Logging, and Retries have also been implemented.
 
Visualization & Reporting 
Insights are delivered through three Power BI Dashboards using DirectQuery:
State-Wise Dashboard:
The objective of this dashboard is to provide high-level geographical summaries across national states.
It helps national policymakers to identify regional disparities for macro-level budget allocation.
 
District-Wise Dashboard:
The objective of this dashboard is to facilitate deep exploration at the local administrative level.
It empowers the local planners with granular data for infrastructure and utility development.
 
Silver Aggregate Dashboard:
This dashboard audits the integrity of transformed data and explores raw demographic splits.
It helps build trust by visualizing the data metrics.
 
How to Run the Project
Prerequisites:
Docker Desktop installed.
Apache Airflow installed through Docker.
Databricks Workspace with PAT token.
Power BI Desktop.
Execution Steps:
Start Docker Desktop 
Start the Apache Airflow: bash/powershell- change to the airflow-docker directory and then use command: docker-compose up -d
Access the Airflow UI: Navigate to localhost:8080 and login with the airflow credentials and then go to DAGs to trigger the populationCensus_sequentialJobs/ population_census_single_job DAG file.
Monitor Databricks: In Jobs and Pipelines, observe the runs for the jobs created, to check whether they are actually trigged and run by airflow or are there any communication issues.
In Databricks, go to the tables created and click open in Power BI Desktop. This will load a connector file. Click the loaded connector file.
Refresh Reports: Open the Power BI .pbix file(created) or login to establish connection, the data will update automatically via DirectQuery.
